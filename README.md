# wayfare

旅行記帳。拍收據 → 自動辨識金額、店名、稅別 → 現金錢包自動扣 → 回國一鍵分帳、匯出 Excel。

**打開就能用：** <https://solarp88.github.io/wayfare/>

📖 **圖文使用說明：** <https://solarp88.github.io/wayfare/guide.html>（第一次用先看這個：怎麼設定、怎麼拍、怎麼分帳、出問題怎麼辦）

- 資料**只存在你自己的手機裡**，沒有伺服器、沒有帳號、沒有月費
- 同一個網址，每個人各自一本帳，互不干擾
- 沒訊號也能拍，有訊號自動補辨識
- 每個人要用**自己的** Gemini API key（免費），申請方法在使用說明第 1 節

---

## 隱私

- 收據照片、金額、位置**全部存在你手機的瀏覽器裡**，沒有上傳到任何伺服器
- 只有辨識的那一刻，照片會送去 Google Gemini 讀，讀完就沒了
- API key 存在你手機，**不會**進備份檔
- 這個 repo 是公開的，但裡面只有程式碼，沒有任何人的資料；使用說明裡的截圖全是示範用的假資料
