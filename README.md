# wayfare

旅行記帳。拍收據 → 自動辨識金額、店名、稅別 → 現金錢包自動扣 → 回國匯出 Excel。

**打開就能用：** <https://solarp88.github.io/wayfare/>

📖 **圖文使用說明：** <https://solarp88.github.io/wayfare/guide.html>（第一次用先看這個）

- 資料**只存在你自己的手機裡**，沒有伺服器、沒有帳號、沒有月費
- 同一個網址，每個人各自一本帳，互不干擾
- 沒訊號也能拍，有訊號自動補辨識

---

## 三步驟開始用

### 第 1 步：申請自己的 Gemini API key（免費）

1. 開 <https://aistudio.google.com/apikey>
2. 用 Google 帳號登入
3. 按 **Create API key** → 複製那串字

> ⚠️ **每個人要用自己的 key。**
> 額度是綁 key 的，共用一把會互相吃掉，而且用量會混在一起看不出誰用的。

### 第 2 步：加到主畫面

**iPhone（Safari）**
開網址 → 下方「分享」→ 往下滑找到 **加入主畫面** → 加入

**Android（Chrome）**
開網址 → 右上角 ⋮ → **安裝應用程式** 或 **加到主畫面**

加完之後桌面會有自己的圖示，點開是全螢幕的，沒有網址列。

### 第 3 步：填設定

打開 App → 最右邊的 **設定**，由上往下填：

| 欄位 | 怎麼填 |
| :-- | :-- |
| 本位幣 | 你平常用的錢。新加坡選 `SGD`、馬來西亞選 `MYR` |
| 當地幣別 | 去日本就 `JPY` |
| 行程首日 / 末日 | 出發和回程的日期 |
| 總預算 | 打算花多少（本位幣）。系統會自己除以天數算每日預算 |
| **現金匯率** | **你換錢時實際拿到的**：1 塊本位幣換到多少日圓 |
| **刷卡匯率** | 銀行大概的匯率。回來看帳單再修正 |
| 付款人 1 | 你的名字 |
| 初始現金 | 出發時帶了多少現金（日圓） |
| 行程 | 一行一個：`旭川 2026-11-29 2026-11-30` |
| API key | 貼上第 1 步複製的那串 |

設定頁最下面有**出發前檢查清單**，會告訴你還缺哪一項。全部打勾才算準備好。

> **為什麼要填兩個匯率？**
> 換現金的成本和刷卡的成本不一樣。市場匯率是一個你從來沒真的付過的價格，
> 拿它算出來的金額看起來精準，其實是假的。所以這裡用你**真正付出的**匯率。

## 怎麼用

### 拍收據
**掃描** → 拍照。拍完**立刻回到相機**，可以連拍，辨識在背景跑。
有問題的那幾筆會標紅點，有空的時候（等車、回飯店）再點進去修。

沒訊號也照樣拍 —— 照片和位置先存著，回到有訊號自動補辨識。

### 沒有收據的消費
販賣機、投幣置物櫃、公車、神社賽錢 —— 用**掃描頁下面的「三秒快速記帳」**。
金額 + 類別，兩下完成。

### 機票、住宿這種行前付的
用 **手動** 那一頁。日期早於行程首日會自動歸成「行前」，
只計一個總數、**不會灌爆你的每日支出**。

### 現金不夠了
首頁會顯示「照目前速度還能撐 X 天」。去 ATM 領錢之後按 **補充現金**。

### 帳對不上了
9 天下來一定會有漏記的。首頁按 **校正餘額**，實際數一次錢包填進去，
差額會被記成「未記錄支出」，而不是假裝沒發生。

### 回國之後
**設定 → 匯出 Excel**（一頁明細、一頁統計）。

⚠️ **資料只在手機裡。** iOS 對長期沒開的網站會清資料，
所以**回國後盡快匯出**，別放著。旅行期間天天在用不受影響。

## 幾個容易誤會的地方

| 你可能以為 | 其實 |
| :-- | :-- |
| Suica 儲值 ¥5,000 是一筆花費 | **不是**。錢只是從口袋換到卡裡。它會扣你的現金錢包，但不算花費 —— 不然用那張卡買東西就重複算兩次了 |
| 免税買東西當場就省了稅 | **不是**。2026-11-01 起日本改新制，店裡付的是**含稅價**，稅要離境時在機場退。App 記成「待退稅」＝**應收**，不是已經省下來的錢 |
| 沒花錢的那天怎麼沒出現在曲線裡 | 有，是 0。缺一天你會以為是漏記 |
| 金額後面那個小字 | 換算成本位幣的參考值，用你設定的匯率算的 |

## 隱私

- 收據照片、金額、位置**全部存在你手機的瀏覽器裡**，沒有上傳到任何伺服器
- 只有辨識的那一刻，照片會送去 Google Gemini 讀，讀完就沒了
- API key 存在你手機，**不會**進備份檔
- 這個 repo 是公開的，但裡面只有程式碼，沒有任何人的資料

## 出問題的時候

| 症狀 | 怎麼辦 |
| :-- | :-- |
| 拍了沒反應、一直排隊 | 多半是沒訊號。回到有訊號會自動繼續 |
| 一直顯示「失敗」 | 設定頁看 API key 對不對；或是當天額度用完了（隔天太平洋時間午夜重置，約日本下午 5 點） |
| 金額都顯示「—」 | 匯率沒填。設定頁補上現金匯率和刷卡匯率 |
| 城市空白或不對 | 定位沒抓到，退回用行程表推。設定頁把行程填完整，或在那筆紀錄裡手動改 |
| 一次匯入太多張跑很慢 | 正常。每分鐘只送 15 張，避免撞到 Google 的速率上限。設定頁可以調 |
